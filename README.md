# Mo‘jaz Manzil — V2 multilingual demo

## Included
- Responsive single-page website.
- Eight language choices: Uzbek, English, German, Russian, Arabic (RTL layout), Chinese, French and Spanish.
- Three sample hiking tour cards with localized names/descriptions, duration, distance, difficulty and sample prices.
- Booking request form.
- Demo admin area: overview, booking list, status changes, tour catalogue and CSV export.
- Booking data saved in browser localStorage.

## Important limitations
This is a frontend demonstration, not a production booking system.
- Booking submissions are stored only in the visitor's browser and are not emailed or sent to a central database.
- The demo admin panel is not protected by production authentication. Do not enter real customer personal data.
- Sample tour details, prices, images and sustainability statements must be verified and replaced with company-approved information before commercial launch.
- External images and fonts require internet access.

## Preview
Open `index.html` in a modern browser.

## Publish free on Netlify
1. Extract this ZIP.
2. Open https://app.netlify.com/drop
3. Drag the extracted `mojaz_manzil_v2` folder onto the page.
4. Netlify will create a temporary `*.netlify.app` demo URL.

## Before production launch
Add a real backend and PostgreSQL database, secure server-side authentication and role permissions, server-side validation, spam protection, email notifications, privacy and cookie notices, backups, monitoring and security testing. Verify company legal documents, route safety data, guide qualifications, insurance, prices and contact details.
